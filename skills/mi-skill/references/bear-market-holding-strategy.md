# 熊市持仓策略：守 vs 割的判断框架

## 背景

2026年7月28日，A股遭遇大幅杀跌：
- 创业板 -7.35%，科创50 -6.33%，深成指 -4.52%
- 光模块板块暴跌：新易盛 -17.13%、中际旭创 -15.69%
- 39只候选池中仅5只收红（12.8%收红率）

## 用户策略判断（实战验证正确）

用户持有的机器人方向个股（如双环传动、江苏雷利）当日相对抗跌（-2.01% / -1.53%），但浮亏已达 -16% / -18%，超过预设止损线。

**用户的判断逻辑：**
1. 市场已进入全面熊市，所有方向都在跌
2. 割肉后换其他方向（如我推荐的鼎龙/紫光/士兰微）也会挨打
3. 机器人方向是当天最抗跌的方向之一（-2.35%均值 vs 半导体-6.36%）
4. 持仓不重（总仓位约10万），等企稳信号出现加一手就能解套
5. 与其两头挨打，不如先守住等反弹

**数据验证（7/28候选池事实）：**
- 机器人方向（-2.35%）排名4/9方向，优于半导体(-6.36%)、AI算力(-3.16%)、功率半(-5.72%)
- 割掉双环换任何一只候选池前10名跌幅更大的股票都会加重亏损
- 通富微电-10%、星网锐捷-9.49%、华润微-7.69%

## 适用框架

### 第一步：评估全市场状态

```
① 上证是否在20日线下方？     → 确认下行趋势
② 是否连续2天放量下跌？     → 恐慌信号
③ 候选池收红率 < 30%？       → 普跌环境
④ 创业板/科创50单日跌幅>5%？ → 极端行情
```

如果≥3个答案为「是」，进入恐慌模式。

### 第二步：定位持仓相对排名

检查持仓在同板块和候选池中的相对位置：

```
持仓涨跌幅排名 = 持仓在候选池中的百分位
  - 在前1/3（如39只中前13名）  → 相对强势，守
  - 在中间1/3                   → 观察，等方向明确
  - 在后1/3                     → 考虑止损
```

### 第三步：「守」策略的条件

同时满足以下条件时可选择坚守：
1. ✅ 全市场处于恐慌/普跌状态（第一步≥3个「是」）
2. ✅ 持仓在候选池中相对排名在前1/3
3. ✅ 持仓方向（如机器人）在各方向中排名前1/3
4. ✅ 持仓方向有中长线催化逻辑（如人形机器人量产）
5. ✅ 持仓仓位不重（总仓位<50%或单只<20%）
6. ✅ 缩量下跌而非放量暴跌

### 第四步：防守加仓三条件

计划在企稳后加仓前，等待以下信号：
1. **缩量止跌**：成交量较恐慌日萎缩50%以上
2. **双底确认**：连续2个交易日不破恐慌日最低价
3. **站上5日线**：收盘价站上5日均线

### 第五步：加仓计算

假设同等金额加仓，摊薄成本后解套所需涨幅：

```
新均价 = (原始成本 + 当前价) / 2   （同等仓位）
解套线 = 新均价
需涨幅度 = (新均价 - 当前价) / 当前价 × 100%
```

如果解套所需涨幅 < 15%，且个股有基本面催化支撑，加仓策略可行。

## 典型错误

- ❌ **机械执行止损**：全面恐慌时所有止损线都会被触发，割了换方向继续挨打
- ❌ **抄底心态**：「跌了这么多可以买了」——恐慌中任何位置都可能被击穿
- ❌ **等反弹再割**：「等反弹到XX再卖」——趋势下行中反弹可能很弱或不存在
- ❌ **满仓守**：守的前提是仓位不重，能留现金加仓。满仓硬扛不是策略是赌博
