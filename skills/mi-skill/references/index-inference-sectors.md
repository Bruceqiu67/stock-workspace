# 指数分化 → 板块轮动推断方法

当东方财富 boardlist 页面 redirect 不可用、push2 API 被封、web_search 超时时，
用指数数据 + 代表股行情反推当日板块轮动。

## 数据源

单一 API 调用即可获得：`qt.gtimg.cn`

```
# 指数（1次调用）
curl -s "http://qt.gtimg.cn/q=sh000001,sz399001,sz399006,sh000688,sh000300,sz399303"

# 代表股（视方向数量，1-2次调用，控制在15只以内）
curl -s "http://qt.gtimg.cn/q=sh603019,sz300660,sz300124..."
```

## 核心推断规则

### 1. 读指数强弱排名

拉6个关键指数后，按涨跌幅排序：

| 指数 | 代码 | 代表什么 |
|------|------|---------|
| 科创50 | sh000688 | AI/半导体/硬科技 |
| 上证指数 | sh000001 | 全市场综合 |
| 沪深300 | sh000300 | 大盘权重 |
| 深证成指 | sz399001 | 深市综合 |
| 创业板指 | sz399006 | 成长/新能源/医药 |
| 国证2000 | sz399303 | 小盘概念股 |

**推断逻辑**：
- 科创50 >> 其他 → 资金向AI/半导体集中
- 沪深300抗跌 + 国证2000领跌 → 大票行情、小票失血
- 上证横盘 + 创业板大跌 → 权重护盘、成长股出逃
- 全指数普跌且跌幅接近 → 系统性风险，无方向可做
- 科创50 + 国证2000齐涨 → 普涨格局，可积极做多

### 2. 结合前日热点验证

从 session_search 或记忆中的前日热门方向，拉2-3只代表股的实时行情验证：

```
前日AI算力强 → 拉中科曙光/浪潮信息
前日机器人弱 → 拉江苏雷利/汇川技术
前日消费强  → 拉贵州茅台/海尔智家
```

### 3. 交叉验证：板块内个股一致性

如果同一方向的多只代表股趋势一致（都在涨或都在跌），说明方向判断可靠。
如果同一方向内的个股走势分化（一个涨一个跌），说明板块已经分歧，需要谨慎。

### 4. 推断结论输出格式

示例：
```
资金轮动推断：
  科创50+1.72% vs 国证2000-1.76%
  → 资金从小盘概念股撤离，向AI算力/半导体集中
  上证-0.14% vs 创业板-0.93%  
  → 权重抗跌，成长股偏弱

方向判断：
  ✅ AI算力/半导体 — 连续2日走强（中科曙光+6.6%）
  ❌ 机器人/自动化 — 连续2日领跌（江苏雷利-6.4%）
  ✅ 安防/防守型 — 抗跌（海康威视+1.6%）
```

## 局限性

- 无法拿到精确的概念板块涨幅排名（缺少板块top N涨幅排序）
- 无法计算"领涨股"的日内最强信号
- 对于冷门或小众方向，可能完全遗漏
- 精度排序：板块排行 > web_search > 指数推断 > 纯凭经验

## 何时使用

仅在前三者（boardlist/web_search/push2）全部失败时使用此方法。
一旦其中一个恢复，优先使用精度更高的方法。
