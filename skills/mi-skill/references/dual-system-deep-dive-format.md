# 双体系深度分析输出格式

> 当用户说「进一步看看排名前N的个股」「深度分析前3只」「逐个点评」时使用的输出模板。
> 构建于 `dual-framework-analysis.md`（方法论层）之上，这里是用户可见的输出格式层。

## 输出结构

```
## #N 个股名称（代码）— 方向 · 业务模式

### 周线全景
[用 emoji 箭头绘制的关键节点价格轨迹]

### 关键发现
- bullet points 列出最重要的技术+基本面信号

### 维度评分（★★★★★）

| 维度 | 评分 | 说明 |
|:---:|:----:|------|
| 技术形态 | ★★★★ | 具体技术特征（缩量程度、底部形态、跌幅收敛） |
| 产业链位置 | ★★★ | 卡脖子程度、是否国产替代直接受益 |
| 关税/政策催化 | ★★★★ | 当前政策事件与个股的相关性 |
| 基本面 | ★★★ | 估值、盈亏状态（周期股可标注"周期底部亏损是常态"） |
| 安全边际 | ★★★★ | 止损距离、位置高低、风险收益比 |

### 综合评级
一句话总结+操作建议。

**参考（仅当有明确入场信号时）：**
- 入场区间：¥XX-XX
- 止损线：¥XX（XX%）
- 加仓/减仓计划
```

## 周线全景格式

用连续箭头+emoji标注关键转折：

```
YYYY.MM → YYYY.MM → YYYY.MM → YYYY.MM → 当前
  XX      XX→XX    XX→XX🔥   XX→XX❄️    XX↕️
  启动    爬升     加速🔥    暴跌❄️      企稳
```

## 评分评分标准

| 分值 | 含义 |
|:---:|------|
| ★★ | 显著短板，需特别注意 |
| ★★★ | 中性/中等 |
| ★★★★ | 明显优势 |
| ★★★★★ | 该维度最佳情况 |

## 维度定义

- **技术形态**：K线排列、量价关系、均线系统、底部/顶部形态、缩量程度相对于自身峰值
- **产业链位置**：公司在供应链中的卡脖子程度、竞争对手数量、客户锁定情况
- **关税/政策催化**：当前政策事件（关税、产业政策、监管变化）对个股的影响方向和力度
- **基本面**：PE/PB/营收增长/利润率，注意周期股在底部时PE为负是常态，需结合行业周期判断
- **安全边际**：当前位置到合理止损位的距离百分比，越低越安全

## 数据采集模式

### 第一轮：日线K线 + 实时行情（同时获取）

```python
# 对每只候选股同时获取日K和行情
mcp_eastmoney_get_kline(code="600460", limit=30, period="daily")
mcp_eastmoney_get_stock_quote(code="600460")
```

### 第二轮：周线K线（判断长期趋势）

```python
# 获取30根周K线覆盖约7个月
mcp_eastmoney_get_kline(code="600460", limit=30, period="weekly")
```

### 第三轮：辅助搜索（可选）

```python
web_search(query="士兰微 功率半导体 IGBT 2026年")
```

## 周线判读要点

| 信号 | 含义 |
|:----|:----:|
| 单周跌幅>15%+天量 | 恐慌性抛售，周线级别调整 |
| 后续周跌幅收敛+缩量 | 卖压枯竭，可能见底 |
| 周线缩量横盘3-5周 | 底部形态构建中 |
| 周线放量突破前高 | 趋势确认向上 |
| 周线位置<50% | 相对低位，有一定安全边际 |
