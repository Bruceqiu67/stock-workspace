# 交易技术规则库


## 多周期进场

- **如果股价横盘调整到位时 → 买入，因为横有多长竖有多高。**
- **如果股价突然下跌形成坑时 → 低吸买入，可能是洗盘或诱空。**
- **如果股价快速跳水时 → 不买入，等待超跌反弹机会，但注意持续杀跌风险。**
- **如果当筹码集中在某个价位时 → 应该分批建仓，避免被反向打压**
- **如果市场处于牛市，价格呈现缓涨急跌 → 主力目的为吸筹，急跌是洗盘，应持股或逢低买入**
- **如果急跌后出现放量反弹 → 洗盘可能结束，拉升即将继续，可考虑买入**
- **如果当外资持续买入或卖出 → 可能成为市场风向标，引导其他资金。**
- **如果当技术图形出现假突破、假底部、假放量时 → 应怀疑图形为人为制造，避免追涨杀跌**
- **如果当指标（KDJ、MACD、均线金叉）共振时 → 警惕是故意引诱，需结合其他因素判断**
- **如果当股价快速上涨、涨停或出现热门新闻时 → 不应追高买入，应等待回调或支撑位**
- **如果当出现放量滞涨、长上影线时 → 应警惕，不买入**
- **如果当买入逻辑彻底破坏（基本面利空、趋势走坏）时 → 果断割肉，保存实力**
- **如果个股回踩日线20日均线后止跌回升 → 视为中周期低吸区间**
- **如果60分钟图出现放量突破、回踩确认或底背离 → 视为小周期买入时机**
- **如果三周期共振（大周期向上、中周期结构到位、小周期信号出现） → 买入成功率高，风险可控**
- **如果下跌原因是基本面恶化（业绩下滑、赛道逆转等） → 视为风险，避免买入**
- **如果下跌原因是市场情绪或短期扰动，长期逻辑未变 → 视为机会，可考虑买入**
- **如果股价放量突破关键压力位（如60日线）后回踩确认支撑 → 果断买入。**
- **如果趋势股上涨途中出现缩量回调至20日线或60日线企稳 → 低吸买入。**
- **如果当价格上穿60日均线，形成多头排列（5MA > 20MA > 60MA），成交量放大，MACD金叉时 → 确认趋势，准备买入**

## 量价信号

- **如果当成交量放大配合价格上涨时 → 趋势健康，可继续持有**
- **如果当成交量萎缩而价格上涨时 → 上涨动力不足，注意回调风险**
- **如果股价在高位放量但涨幅有限时 → 坚决出局观望，主力派发筹码。**
- **如果急涨后出现高位放量 → 主力可能正在借机出货，应警惕风险**
- **如果股价跌破20日线或60日线，或MACD死叉放量下跌 → 果断止损。**
- **如果成交量逐步萎缩，股价仍沿均线上行 → 持股，主力未撤退。**
- **如果当均线死叉、放量下跌破位时 → 软止损，考虑减仓或撤退**
- **如果当跌破趋势线或关键均线并放量时 → 卖出**
- **如果当出现放量长阴或反转K线（如黄昏之星、射击之星）时 → 卖出**
- **如果当MACD死叉、量价背离严重时 → 卖出**
- **如果情绪票出现放量长上影线、炸板断板、天地板、高位巨量阴线或连续缩量下跌 → 应视为见顶信号，及时卖出**
- **如果竞价成交量远超前几日均值 → 可能有资金抢筹**
- **如果竞价成交量未放大 → 可能是散户跟风**
- **如果当量缩价跌时 → 视为市场观望，卖压不强但买盘也少，可能是缩量调整，尤其在下跌末期或横盘整理阶段，可能是筑底信号**
- **如果当高位出现放量大阴线或断头铡刀时 → 应视为顶部信号，考虑卖出**
- **如果当整理后放量下跌或跌破整理区下轨时 → 视为伪空中加油或出货信号，应及时止损**
- **如果股价在压力位附近缩量滞涨 → 考虑止盈卖出**
- **如果股价大涨后出现历史最大成交量，次日无力新高 → 放量滞涨卖出**
- **如果连涨3天以上，最后一天冲高回落 → 放量滞涨卖出**
- **如果股价高位放量大跌，跌幅5%以上 → 放量下跌卖出**

## 均线趋势

- **如果当技术指标出现背离（如价格新高但MACD未新高）时 → 可能反转，考虑减仓或离场**
- **如果市场趋势不明朗时 → 宁可休息，不盲目交易。**
- **如果当交易者不频繁交易，重视趋势和基本面，持有优质资产或指数基金时 → 长期收益稳定，但需要眼光、定力和资金结构**
- **如果当投资者是普通人时 → 不应做短线，而应选择趋势埋伏或宽基指数配置**
- **如果当已经追高被套且趋势依旧向上时 → 可以耐心等待反弹**
- **如果当已经追高被套且趋势明显见顶转弱时 → 不能死扛，要考虑止损或换股**
- **如果月线MACD刚刚金叉或周线站稳MA60 → 视为大周期方向确认，值得参与**
- **如果趋势未破坏（未跌破20日线、60日线，均线多头排列） → 继续持股，不主动卖出。**
- **如果股价沿5日线上涨，未失守5日线 → 继续持有，不卖出。**
- **如果股价跌破5日线 → 移动止盈，部分止盈。**
- **如果当MACD死叉且跌破20日线时 → 全清仓位**
- **如果趋势票出现高位横盘量能背离、头肩顶跌破颈线、三重顶冲高失败、箱体跌破下轨或MACD顶背离/均线死叉 → 应视为顶部形成，卖出离场**
- **如果当处于冰点末期 → 不操作或轻仓守底部趋势票**
- **如果当价涨量增时 → 应视为趋势强化，健康上涨，可继续持有或做多**
- **如果当价跌量增时 → 应警惕趋势反转或下跌加速，下跌初期可能探底，下跌末期可能见底**
- **如果DIF下穿DEA（死叉） → 考虑卖出，尤其在下跌趋势中**
- **如果股价创新高但MACD未创新高（顶背离） → 不宜追高，可考虑止盈或减仓**
- **如果股价创新低但MACD未创新低（底背离） → 不宜盲目杀跌，观察止跌信号**
- **如果MACD柱状图缩小 → 趋势动能减弱，可能进入震荡或反转**
- **如果MACD柱状图由负变正 → 市场可能反弹**

## MACD/KDJ/RSI

- **如果DIF和DEA在零轴下方且出现死叉 → 卖出信号更危险，可能继续下跌**
- **如果RSI > 70且市场震荡 → 考虑卖出**
- **如果RSI死叉且股价跌破重要支撑 → 卖出信号更可靠**
- **如果顶背离出现 → 不宜追高，可逐步减仓**
- **如果当死叉发生在零轴下且无底部形态支持时 → 不宜抄底，应逢高减仓或顺势做空**

## K线形态

- **如果当龙头见顶大阴线，跟风崩盘 → 坚决离场，空仓等待冰点**
- **如果筹码集中度高（>70%）且呈单峰形态 → 主力控盘强，股价启动后易拉升，抛压小。**
- **如果股价上涨乏力，出现连续上影线、量能缩小 → 考虑止盈卖出**
- **如果股价短期连续涨停或大阳线，上涨角度超过60°，短期涨幅超50% → 加速上涨后卖出**
- **如果股价形成双顶或头肩顶形态，跌破颈线 → 双顶/头肩顶卖出**
- **如果孕线出现在上涨行情高位 → 可能预示上涨动能衰竭，市场犹豫，可能出现反转或盘整。**
- **如果孕线出现在下跌行情低位 → 可能预示下跌动能减弱，市场酝酿反弹或震荡筑底。**
- **如果孕线后出现向下跌破母线低点 → 视为看跌信号。**
- **如果当看K线图累计达到1000小时时 → 会开始有初步盘感**
- **如果当看K线图累计达到1万小时时 → 才算真正建立交易直觉**
- **如果当股价放巨量拉大阳线时 → 应该考虑卖出，因为这可能是庄家出货信号**
- **如果当股价放巨量大阴线时 → 应该考虑卖出，因为这可能是庄家出货信号**
- **如果第三根阳线之后追高 → 应谨慎，防止短线回调**
- **如果当盘面一天三四次急拉急砸、上影线多、情绪失控时 → 说明盘面不干净，不宜参与**
- **如果当学习短线技术（如K线、打板）看似简单时 → 新股民会认为短线容易入门，从而首选短线**

## 卖出/顶部

- **如果当亏损达到预设止损点时 → 应果断离场，避免亏损扩大**
- **如果股价快速冲高时 → 不卖出，等待连续拉升后找卖点。**
- **如果当持有股票一个月内不涨时 → 应执行时间止损，卖出该股**
- **如果当交易者没有系统、不懂风控、听消息跟风时 → 最终多数亏损离场**
- **如果基本面恶化 → 果断卖出**
- **如果突然放巨量破位 → 警惕主力撤退，考虑卖出。**
- **如果当入场后5-7个交易日内无明显上涨时 → 时间止损，考虑减仓或撤退**
- **如果当上涨15%-20%时 → 固定目标止盈，减仓**
- **如果当龙头4-5板以上，涨停批量出现 → 快进快出，控制回撤，开始减仓**
- **如果市场处于空头循环时 → 反弹往往是卖出或做空的机会，应反弹减仓、做空**
- **如果当量增价跌时 → 视为抛压沉重，可能是主力出货，短期有下跌风险，尤其在顶部区域或利空消息后**
- **如果当振幅大于涨幅时 → 视为冲高回落或震荡上行，表明多空分歧较大，需警惕高位见顶或诱多风险。**
- **如果股价跌破前期重要支撑位（如前低、箱体底部） → 止损卖出**
- **如果出现日线级别顶背驰 → 阶段性顶部成立，可能开始主跌浪，需减仓离场或反向布局**
- **如果BIAS12和BIAS24长时间处于+4%至+8%且转头向下 → 考虑波段减仓**
- **如果当股价涨多了时 → 适当减仓，但保留至少五成仓位**
- **如果当股价回调企稳时 → 接回之前减仓的部分**
- **如果当无法做到知行合一时 → 难以在牛市见顶后全身而退**
- **如果当一段涨幅兑现后 → 应逐步减仓锁定利润，为下一波行情腾出空间**
- **如果当股价大涨后出现回调，投资者因贪婪想抓住全部涨幅而恐慌离场时 → 建立分批止盈策略，在上涨过程中分批卖出，追求‘吃鱼身中段’。**

## 止损/风控

- **如果当看到身边人赚钱或市场火热时 → 应保持冷静，不冲动入市，牢记股市有风险**
- **如果当听到‘这股必涨’等一致看多声音时 → 应警惕风险聚集，不追高**
- **如果当盈利达到预设止盈点时 → 应落袋为安，不贪心**
- **如果连续大涨后 → 注意回调风险。**
- **如果当股票属于成长股时 → 应关注其业绩和营收增速，但需注意高估值风险。**
- **如果当股票属于题材股时 → 应警惕炒作风险，业绩不一定兑现。**
- **如果当股票属于ST股时 → 应避免投资，因风险高且可能退市。**
- **如果本金规模较小且时间充裕且能承受较高风险 → 适当参与短线游资操作，但需警惕追高风险，严格设置止损**
- **如果当交易者以交易为职业，具备强风控、纪律和心理素质时 → 极少数能稳定盈利，多数在高压下身心俱疲后退出**
- **如果当热点题材出现时 → 避免追逐，因为风险最快累积**
- **如果当追求短期高收益时 → 应警惕看不见的风险和陷阱**
- **如果当加仓时 → 必须在盈利基础上加仓，找关键点位并设止损。**
- **如果当已有一定市场经验时 → 可以在控制好风险的前提下，逐步加入个股交易，让复利和进攻一起发挥作用。**
- **如果当量缩价涨时 → 视为上涨动力不足，买盘跟进乏力，可能是反弹或诱多，需警惕后市回落，尤其在反弹末期或临近压力位**
- **如果当价跌量缩时 → 应视为下跌衰竭，可能止跌，接近支撑位时可关注反弹**
- **如果当斜率大且向上时 → 涨得猛，动能强，但风险逐渐增大**
- **如果筹码在高位且股价下跌 → 高位套牢，反弹压力大**
- **如果股价下跌至历史前期低点或震荡区域底部时 → 若该低点多次触及不破，则支撑较强**
- **如果股价回到成交密集区（筹码峰）时 → 该区域可能提供支撑**
- **如果BIAS6 > +6%（个股）或 > +4%（大盘/权重股） → 考虑短线止盈或规避风险**

## 情绪周期

- **如果当游资炒作情绪达到极致时 → 游资会完成退出，行情往往来得快去得也快**
- **如果当涨停家数多且炸板率低时 → 市场情绪强势，可积极操作**
- **如果当情绪失控（贪婪/恐惧）时 → 应该暂停交易，按计划操作**
- **如果当市场情绪极度贪婪或恐惧时 → 应反思自身情绪，避免羊群效应**
- **如果当投资者人品不好、急功近利、投机取巧时 → 容易受到市场情绪干扰，频繁操作，陷入追涨杀跌的恶性循环，难以长久立足**
- **如果当跌停、天地板频现，情绪冰点 → 轻仓观察，准备捡便宜，关注新题材萌芽**
- **如果当刚入场时 → 应该先从宽基ETF开始，理解市场节奏和情绪规律。**
- **如果策略回测表现好但实盘差时 → 检查数据偏差、滑点、成本、情绪干扰等因素**
- **如果当发生亏损时 → 区分亏损是系统错误、情绪错误还是概率必然**
- **如果当市场处于情绪驱动的短炒模式时 → 应警惕追涨杀跌的恶性循环**
- **如果当股票处于末升浪阶段（主升浪已完、情绪驱动） → 应避免追逐末升浪高潮，转而寻找尚未被市场完全发现的优质资产**
- **如果当 ROE 稳定时，PB 越低 → PE 越低（市场情绪低迷，估值便宜）**
- **如果当股票跌破支撑没人接、上涨靠情绪、分时急拉急砸时 → 说明主力控盘弱**
- **如果当交易者沉浸在单笔盈亏、短期波动和情绪中时 → 应该跳出当前视角，从系统、长期、规则的角度重新审视**
- **如果当利益与情绪深度介入，判断被结果绑架时 → 应该暂时抽离，回到观察者位置，看清市场全貌和自身行为**
- **如果当资金是短线跟风盘（盯分时、情绪化、频繁买卖）时 → 主力会通过洗盘将其清除，因其消耗拉升动能**
- **如果当失败后只发泄情绪时 → 会停留在同一认知层级，反复循环失败**
- **如果当使用机构思维分析游资票时 → 应避免逻辑错位，用游资的分析框架（情绪、速度、接力）**
- **如果当面对短期涨跌时 → 应依靠交易系统保持情绪稳定，不被短期波动左右。**
- **如果当情绪极度悲观、政策明确转向、估值处于历史底部区间三者同时出现时 → 可以激进一点，否则宁可错过也不重仓赌底**
