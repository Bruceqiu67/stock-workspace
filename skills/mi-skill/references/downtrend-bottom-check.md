# 个股底部检查框架（下跌趋势中评估个股是否见底）

当一只个股处于明确下跌趋势中，且用户考虑「守还是割」或「等企稳加仓」时，使用此框架逐项打分。

## 六维底部检查

### 维度1：三重底/双底形态

检查近8-10个交易日的日K线低点：

```
最近三次低点：
  L1 = 最早一次低点
  L2 = 中间一次低点  
  L3 = 最近一次低点

如果 L3 > L2 > L1  → 底部抬高 ✅ 强势企稳
如果 L3 ≈ L2 ≈ L1  → 底部平行 ⚠️ 横盘筑底
如果 L3 < L2       → 底部下移 ❌ 趋势延续
```

**数据来源**：腾讯日K线 `curl -s "https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=sz300660,day,,,60,qfq"` → 取最近20条K线的 low 字段。

### 维度2：成交量萎缩程度

```
近5日均量 = sum(近5日成交量) / 5
近20日均量 = sum(近20日成交量) / 20
缩量比 = 近5日均量 / 近20日均量

缩量比 < 0.5  → 深度缩量 ✅ 惜售信号
缩量比 0.5~0.7 → 适度缩量 ⚠️ 仍需观察
缩量比 > 0.7  → 无量或放量 ❌ 未出清
```

### 维度3：均线排列

```
检查 MA5、MA10、MA20 的排列关系：

MA5 > MA10 > MA20    → 多头排列 ✅ 上升趋势
MA5 > MA10, MA10 < MA20 → 短多长空 ⚠️ 反弹中
MA5 < MA10 < MA20    → 空头排列 ❌ 下跌趋势
当前价 > MA5         → 短线偏强 ✅
当前价 ≈ MA5         → 贴边 ⚠️ 待确认
当前价 < MA5         → 短线偏弱 ❌
```

**企稳的第一信号**：收盘价站上MA5（贴边不算，需明确突破）。

### 维度4：52周相对位置

```
相对位置 = (当前价 - 52周最低) / (52周最高 - 52周最低) × 100%

< 10%  → 接近历史底部  ✅ 价格够低
10-30% → 偏低位置      ⚠️ 可接受
30-50% → 中位          ⚠️ 不便宜
> 50%  → 高位          ❌ 下跌空间大
```

### 维度5：近8日价格范围检查

检查个股在最近8个交易日内的最低价和当前价关系：

```
近8日最低 = min(近8日 low)
当前距最低 = (当前价 - 近8日最低) / 近8日最低 × 100%

< 2%  → 还在最低附近   ⚠️ 弱势
2-8%  → 脱离底部区域   ✅ 初步企稳
> 8%  → 明显反弹       ✅ 反弹确认
```

### 维度6：相对强度（vs 大盘/板块）

对比个股与大盘/板块/同行的同期跌幅：

```
个股跌幅 vs 大盘（如上证/创业板）
个股跌幅 vs 同行（同板块其他个股）
个股跌幅 vs 候选池均值

个股跌幅 << 大盘/同行 → 相对强势 ✅
个股跌幅 ≈ 大盘/同行 → 跟随型 ⚠️
个股跌幅 >> 大盘/同行 → 弱势股 ❌
```

## 综合打分表

| 维度 | 得分规则 | 满分 |
|:----|:--------|:---:|
| 三重底/双底 | 底部抬高=30, 平行=15, 下移=0 | 30 |
| 缩量比 | <0.5=20, 0.5-0.7=10, >0.7=0 | 20 |
| 站上MA5 | 明确站上=20, 贴边=10, 未站上=0 | 20 |
| 52周位置 | <10%=15, 10-30%=10, >30%=0 | 15 |
| 近8日位置 | >8%=10, 2-8%=5, <2%=0 | 10 |
| 相对强度 | 明显强势=5, 跟随=3, 弱势=0 | 5 |
| **总分** | | **100** |

- **≥70分**：见底确认，可考虑加仓
- **50-69分**：初步企稳，等进一步确认
- **<50分**：未见底，继续观望或止损

## 数据获取脚本

```bash
# 单次获取所有数据
CODE="sz300660"  # 替换为目标代码

# 1. 日K线
curl -s "https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=${CODE},day,,,60,qfq" -o /tmp/kline_${CODE}.txt

# 2. 实时行情
curl -s "https://qt.gtimg.cn/q=${CODE}" | iconv -f GBK -t UTF-8

# 3. 计算各维度
python3 -c "
import json
d = json.load(open('/tmp/kline_${CODE}.txt'))
data = d['data'][list(d['data'].keys())[0]]['qfqday'] or d['data'][list(d['data'].keys())[0]]['day']
closes = [float(k[2]) for k in data[-20:]]
lows_8 = [float(k[4]) for k in data[-8:]]
highs_52 = max(float(k[3]) for k in data)
lows_52 = min(float(k[4]) for k in data)
vols = [float(k[5]) for k in data[-20:]]

ma5 = sum(closes[-5:])/5
ma10 = sum(closes[-10:])/10
v5 = sum(vols[-5:])/5
v20 = sum(vols)/20

print(f'三重底检查: 三次低点={lows_8[::3]}')
print(f'缩量比: {v5/v20:.2f}')
print(f'均线: MA5={ma5:.2f} MA10={ma10:.2f} (当前{closes[-1]:.2f})')
print(f'52周位置: {(closes[-1]-lows_52)/(highs_52-lows_52)*100:.1f}%')
print(f'近8日低:{min(lows_8):.2f} 当前距最低:{((closes[-1]/min(lows_8))-1)*100:.1f}%')
"
```

## 注意事项

- 此框架适用于**下跌趋势中评估单一个股是否筑底**，不适用于正常市场选股
- 所有信号必须使用**真实数据**，不可凭印象估算
- 六个维度应全部检查后综合判断，单一维度好（如52周位置极低）不代表见底
- 大盘系统性风险未解除时，个股底部可能被同步击穿，需结合 `bear-market-holding-strategy.md` 的全市场状态评估
