# SKILL.md & rules.md 独立测试路线

## 目的

这份文档是一套**可由任何第三方模型或人独立执行的测试路线**。
执行者不需要知道 SKILL 是怎么生成的，只需要用它做判断，然后记录结果。

每个测试都有明确的**操作指令**和**通过/失败标准**。

---

## 准备工作

执行此测试需要：

1. `SKILL.md` — 当前的交易技术分析框架
2. `rules.md` — 8类366条技术规则
3. 实时/历史市场数据（可从新浪财经、东方财富等公开API获取）

---

## 测试 1：规则溯源审计

### 目标
确保 rules.md 中的每条规则都能追溯到源材料（书或推文），没有凭空编造。

### 执行方法

1. 从 `rules.md` 中随机抽取 **20 条规则**
2. 对于每条规则，打开 `output/book_skeleton.md`（书骨架）
3. 搜索规则中的关键词是否存在于书骨架中
4. 记录结果

### 评判标准

| 结果 | 判定 |
|------|------|
| 20 条中 ≥18 条可在书中找到 | ✅ 通过 |
| 15-17 条可在书中找到 | ⚠️ 部分通过，需标注未溯源规则 |
| <15 条可追溯 | ❌ 不通过 |

### 记录模板

```
规则1: "如果MA5 > MA20且放量 → 买入"
  书中匹配: ✅ (在【趋势交易的交易系统】章节找到)
  
规则2: "如果... → ..."  
  书中匹配: ❌ (未在书骨架中找到任何相关关键词)
```

## 测试 2：内部矛盾检测

### 目标
确保 SKILL 和 rules 内部没有相互矛盾的规则。

### 执行方法

1. 从 SKILL 中提取所有**原则**（共6条）
2. 从 rules.md 中提取所有规则
3. 逐一检查是否存在**相反条件 相同结论** 或 **相同条件 相反结论**

### 检查清单

```
检查1: 是否有两条规则的条件相同但一个说"买入"另一个说"卖出"？
检查2: 是否有规则违反了 SKILL 中的原则（如"不冲高不卖" vs "冲高就卖"）？
检查3: 是否有两条规则一个说"持有"一个说"减仓"且条件不冲突？
检查4: Persona 的特质是否与 rules 中的操作建议矛盾？

记录格式:
  [矛盾] 条件 "MA5>MA20" → 规则A说"买入", 规则B说"观望"
  [矛盾] 条件 "放量突破" → 规则说"买入", 但原则说"让市场先确认"
```

### 通过标准

- 0 个逻辑矛盾 → ✅ 通过
- 1-2 个可解释的矛盾 → ⚠️ 需评审
- ≥3 个矛盾 → ❌ 不通过

## 测试 3：市场回测

### 目标
用真实的历史数据验证规则的可行性。

### 执行方法

取以下 5 个已知市场区间（或使用执行者自己熟悉的市场区间）：

| 编号 | 区间 | 已知特征 | 期望判断 |
|------|------|---------|----------|
| 3a | 上证 2024/1-2024/3 | 2635→3090 反弹 | 需识别底部放量→买入信号 |
| 3b | 上证 2024/5-2024/9 | 3174→2689 下跌 | 需发出止损/观望信号 |
| 3c | 上证 2024/9-2024/10 | 2689→3674 暴涨 | 需识别放量突破→买入 |
| 3d | 当前 2026/7 数据 | MA5>MA20但MA20<MA60 | 应判断为非共振→观望 |
| 3e | 选一个自己熟悉的行情 | — | — |

### 操作步骤

对每个区间：

```
1. 获取该区间开始和结束时的技术指标（价格、MA5/20/60、成交量）
2. 应用 SKILL 的多周期框架判断方向
3. 在 rules.md 中查找适用的具体规则
4. 记录 SKILL 给出的操作建议
5. 对比实际走势：如果按建议操作，结果如何？

记录格式:
  区间: 2024/1-2024/3 (2635→3090)
  开始指标: 价格2670, MA5 2680, MA20 2720, MA60 2850
  SKILL分析: MA5<MA20<MA60 空头排列; 价涨量增 → 反弹
  rules匹配: 规则"底部放量长阳→反转信号"适用
  操作建议: 等待放量突破MA60确认
  实际结果: 后续放量突破MA60, 反弹至3090
  判断: 规则建议保守但正确 (错过初期但确认后入场安全)
```

### 评分

| 结果 | 分数 |
|------|------|
| 5/5 区间判断方向正确 | 10/10 |
| 4/5 区间判断方向正确 | 8/10 |
| 3/5 区间判断方向正确 | 6/10 |
| <3/5 | 4/10 |

## 测试 4：盲测（未知场景）

### 目标
测试 SKILL 在**新场景**（执行者没见过的行情）下的判断能力。

### 执行方法

1. 执行者用自己的知识/经验构造 **3 个真实的市场场景**
2. 这些场景执行者知道答案，但 SKILL 不知道
3. 执行者只看 SKILL.md + rules.md，不看场景的答案
4. 用 SKILL 分析并记录结论

### 场景模板

```
场景A: 某指数连续下跌15%，今日突然放量上涨3%，成交量是昨日的2.5倍
  SKILL分析: [执行者填写]
  rules匹配: [执行者填写引用的规则]
  操作建议: [执行者填写]
  执行者已知答案: [执行者事后填写真实发生了什么]
  判断: 一致/不一致
```

### 通过标准

- 3/3 一致 → ✅
- 2/3 一致 → ⚠️
- ≤1/3 → ❌

## 测试 5：极限条件测试

### 目标
测试 SKILL 在极端市场条件下的表现。

### 执行方法

对以下极端条件，SKILL 能给出什么结论？

| 条件 | 期望 | 实际结论 |
|------|------|---------|
| 连续涨停后巨量换手 | 识别为顶部信号 | [填写] |
| 连续跌停后地量 | 识别为止跌但需确认 | [填写] |
| MA5/20/60 完全粘合 | 识别为无方向 | [填写] |
| 放量突破历史新高 | 识别为趋势确认 | [填写] |
| 突发利空跳空低开-5% | 应等待非恐慌信号 | [填写] |

### 通过标准

- 5/5 判断合理 → ✅
- 3-4/5 判断合理 → ⚠️
- <3 → ❌
