## 测试 4: 盲测（未知场景）

### 场景 A: 连续阴跌后的突然放量涨停

条件: 连续下跌 20 个交易日累计跌幅 8%，今日突然放量涨停（+9.8%），成交量是前 5 日均量的 3 倍。MA5 刚上穿 MA20，MA60 仍在上方压制。

SKILL 分析: MA60 压制，三周期未共振 → 不满足买入条件。单日放量涨停可能是反弹而非反转。等待放量突破 MA60 确认后再入场。
判断: **✅ 一致** — 等待确认更安全

### 场景 B: 高位横盘后的放量破位

条件: 高位横盘 3 个月，MA5/MA20/MA60 完全粘合。今日放量下跌 3% 跌破所有均线，成交量放大到均量 2 倍，MACD 死叉。

SKILL 分析: MA 粘合后放量破位 → 方向选择向下。MACD 死叉+跌破均线 → 多重卖出信号叠加。果断清仓。
判断: **✅ 一致** — 正确识别为卖出信号

### 场景 C: 缩量阴跌到地量后的横盘

条件: 从高点下跌 25%，近 10 日成交量持续萎缩至历史最低（地量），底部窄幅震荡，MA5/MA20 走平。

SKILL 分析: 地量 → 抛压衰竭，冰点阶段。不应此时卖出（抛压已衰竭），也不应重仓买入（未见放量反转）。轻仓试探或等待。
判断: **✅ 一致** — 正确建议等待而非抄底

### 盲测评分: 3/3 一致 → ✅ 通过
