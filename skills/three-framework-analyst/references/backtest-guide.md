# 历史回测指南

> 回测版本：v2.0 | 数据：Sina 上证指数日K | 取数 250 日，回测最近 90 日
> 目标定义：**次日收盘相对前收**（next close vs prev close），预测与验证使用同一公式。

## 方法论

简化版回测：只用 K 线数据模拟 16:00 复盘时的预判逻辑。

**输入**：Day N 的前收、开高低收、振幅
**输出**：Day N+1 方向预判（偏多/偏空/震荡）+ 支撑/压力
**验证**：Day N+1 收盘相对 Day N 收盘的涨跌

**预测逻辑（简化）**：
- 今日涨>1.5% → 偏多延续 / 震荡偏空（振幅>3%）
- 今日跌<-1.5% → 惯性下跌 / 偏空弱反弹
- 今日涨跌<0.5% → 窄幅震荡
- 中间区间：偏多/震荡 或 偏空/震荡

**评分与统计**：
- 方向分 1.0/0.0（预判方向 vs 实际方向）
- 区间分 0.0~1.0（收盘在支撑/压力范围内）
- 95% Wilson 置信区间
- 滚动 20 日方向准确率（min/mean/max）
- 训练段/测试段切分（前 70% / 后 30%）
- 交易成本 0.05%/边 + 滑点 0.05%/边，输出方向性策略净收益

## 基准对照

v2.0 每次回测同时输出：

| 基准 | 含义 |
|---|---|
| `always_up` | 每天都预判上涨 |
| `always_down` | 每天都预判下跌 |
| `random` | 固定随机种子（42）三分类 |
| `momentum` | 次日方向 = 今日方向 |

只有稳定超过这些基准，才能说明预判逻辑有增量信息。

## 历史 Baseline（旧口径，不可用于校准）

> ⚠️ 2026-07-13 的 60.7% baseline 使用 `(close-open)/open` 计算“当日涨跌”，
> 并与次日同公式比较，即预测/验证的都是**日内方向**，不是“次日收盘相对前收”。
> 因此该 baseline **不能**用于校准 `prediction_tracker`，也不能证明完整三框架有效。
> 下方仅保留为历史记录。

```
数据: 2025-09-10 ~ 2026-07-13（200 个交易日）
回测: 2026-03 ~ 2026-07（89 个交易日）
方向准确率  60.7%    (54/89)
区间准确率  97.8%    (87/89)   ← 算法太松，仅供参考
综合分      79/100
```

## 关键发现（旧口径）

1. **60.7% 是日内方向基线** — 与真实预判目标不同，不可直接比较。
2. **区间准确率 98% 太松** — 区间算法需要收紧，不应作为有效性指标。
3. **偏空预判系统性偏悲观** — 旧口径的偏差结论需要在新口径下重新验证。
