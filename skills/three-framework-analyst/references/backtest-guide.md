# 历史回测指南

> Baseline 建立于 2026-07-13 | 数据：Sina API | 89 个交易日

## 方法论

简化版回测：只用 K 线数据模拟 16:00 复盘时的预判逻辑。

**输入**：当日收盘价、涨跌幅、振幅、最高、最低
**输出**：方向预判（偏多/偏空/震荡）+ 关键区间（支撑/压力）
**验证**：次日实际收盘数据

**预测逻辑（简化）**：
- 今日涨>1.5% → 偏多延续 / 震荡偏多
- 今日跌<-1.5% → 惯性下跌 / 偏空
- 今日涨跌<0.5% → 窄幅震荡
- 中间区间：偏多/震荡 或 偏空/震荡

**评分**：
- 方向分 1.0/0.0（预判方向 vs 实际方向）
- 区间分 0.0~1.0（收盘在支撑/压力范围内）

## Baseline 结果

```
数据: 2025-09-10 ~ 2026-07-13（200 个交易日）
回测: 2026-03 ~ 2026-07（89 个交易日）

方向准确率  60.7%    (54/89)
区间准确率  97.8%    (87/89)   ← 算法太松，仅供参考
综合分      79/100

月度:
  2026-03  71%  ← 趋势市场，有效
  2026-04  62%
  2026-05  44%  ← 震荡市，低于随机
  2026-06  62%
  2026-07  62%

偏差分析:
  偏多预判 62% 正确
  偏空预判 48% 正确  ← 系统性偏悲观
```

## 关键发现

1. **60.7% 是只用 K 线的 baseline** — 完整三框架（MCP+板块+资金流）预期更高
2. **5 月 44% 不是框架的锅** — 回测只用 K 线，真实系统有更多数据维度
3. **震荡市判断需要完整框架** — 不要用简单规则拍脑袋（见 Pitfalls）

## 局限性

- 没有使用 MCP 板块流向数据
- 没有使用持仓数据
- 没有使用候选池
- 没有产业链逻辑验证
- 区间计算偏松（97.8% 准确率说明区间太宽）
