# 复盘错误分类（tracker.py report --by-type）

> 2026-07-13 实现

## 基础逻辑

```python
classify_prediction(base_scenario) → "偏多" / "偏空" / "震荡" / "弱反弹" / "未分类"
```

从 `base_scenario` 文本中按关键词归类：

| 类型 | 关键词 |
|------|--------|
| 偏多 | 涨、阳、反弹、偏多、延续、上行、探底回升 |
| 偏空 | 跌、阴、偏空、下跌、惯性、下行、回调 |
| 震荡 | 震荡、窄幅、横盘、平 |
| 弱反弹 | 弱反弹 |

## 错误分类

| 错误类型 | 判定条件 |
|----------|---------|
| 方向看反 | 预判涨→实际跌，或预判跌→实际涨，且波动>0.5% |
| 震荡误判 | 预判有方向→实际振幅<0.5%，或预判震荡→实际波动>=1.5% |
| 正确 | 方向正确 |

## 偏差分析

- 偏多 vs 偏空方向准确率对比
- 差值>10个百分点 → 标记系统性偏乐观/悲观

## 用法

```bash
python3 ~/.hermes/data/predictions/tracker.py report --by-type
```
