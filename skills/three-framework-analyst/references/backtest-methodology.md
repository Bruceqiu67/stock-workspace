# 预判系统回测方法论（v2.0）

## 核心目标

验证分析框架的预判能力：**Day N 收盘后预判 Day N+1 收盘相对 Day N 收盘的涨跌，次日用同一公式验证**。

> 关键修正：预测与验证都必须使用“次日收盘相对前收”。禁止用 `(close-open)/open`
> 的日内方向冒充次日预判；旧口径的 60.7% baseline 不可用于校准。

## 数据源

| 数据 | 来源 | 说明 |
|------|------|------|
| 上证指数日K线 | Sina API: `money.finance.sina.com.cn/quotes_service/api/json_v2.php/CN_MarketData.getKLineData?symbol=sh000001&scale=240&ma=no&datalen=250` | 返回 OCHL + volume |
| 腾讯实时行情 | `qt.gtimg.cn/q=sh000001,...` | 仅用于补充当日快照，不参与回测评分 |

## 回测流程

```
输入：历史日K线（OCHL+volume），取数 250 日
   ↓
逐日模拟：对第 N 天，用第 N 天与前收生成第 N+1 天预判
   ↓
对照第 N+1 天实际数据（次日收盘 vs 第 N 天收盘）评分
   ↓
累计统计 → 基准对照 → 月度/滚动窗口 → 训练/测试切分
```

## 预判模拟逻辑（简化版）

基于当日收盘数据判断明日方向，不使用未来信息：

```
今日涨>1.5% + 振幅>3% → 震荡偏空（冲高回落风险）
今日涨>1.5% + 振幅≤3% → 偏多延续
今日涨0.5~1.5%         → 偏多/震荡
今日±0.5%以内           → 窄幅震荡
今日跌0.5~1.5%         → 偏空/震荡
今日跌>1.5% + 振幅>3% → 惯性下跌
今日跌>1.5% + 振幅≤3% → 偏空/弱反弹
```

区间计算：
- 支撑 = 今日最低价 × (1 - 0.8% × 波动因子)
- 压力 = 今日最高价 × (1 + 0.8% × 波动因子)
- 波动因子：振幅>4%→1.5, 振幅<1%→0.6, 默认1.0

## 评分体系

| 维度 | 满分 | 判定 |
|------|:----:|------|
| 方向分 | 1.0 | 预判方向与实际涨跌方向一致=1.0，否则=0.0 |
| 区间分 | 1.0 | 收盘在支撑/压力之间=1.0，否则按偏离度线性衰减 |
| 综合分 | 0-100 | (方向分+区间分)/2 × 100 |

方向判定规则：
- 偏多类预判 → 实际涨>0 则方向正确
- 偏空类预判 → 实际跌<0 则方向正确
- 窄幅震荡 → 实际|涨跌|<1% 则方向正确

## 统计与稳健性

- **全部样本保存**：`results` 不再截断前 20 条。
- **基准**：always-up / always-down / random（seed=42）/ momentum。
- **置信区间**：方向准确率输出 95% Wilson 区间。
- **滚动窗口**：20 日方向准确率的 min/mean/max。
- **训练/测试切分**：前 70% 训练段、后 30% 测试段分别报告。
- **成本**：单边成本 0.05% + 滑点 0.05%，方向性策略输出累计/平均净收益。
- **版本**：结果写入 `backtest_version`、数据源、取数天数、回测天数、生成时间。

## 关键约束

1. 预测与验证公式必须一致：`(next_close - current_close) / current_close`。
2. 不允许使用未来数据；回测循环只读取第 N 天及之前的数据生成预判。
3. 区间分不能因为“区间太宽”而虚高；报告中应同时看方向分与基准对照。
4. 旧口径（开盘→收盘）的 baseline 只能作为历史记录，不能用于调参或证明框架有效。
