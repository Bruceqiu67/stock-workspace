# 预判系统回测方法论

## 核心目标

验证分析框架的预判能力：**每日收盘后基于当日数据预判次日走势，次日验证评分**。

## 数据源

| 数据 | 来源 | 说明 |
|------|------|------|
| 上证指数日K线 | Sina API: `money.finance.sina.com.cn/quotes_service/api/json_v2.php/CN_MarketData.getKLineData?symbol=sh000001&scale=240&ma=no&datalen=N` | 返回 OCHL + volume，最长约 200 条 |
| 腾讯实时行情 | `qt.gtimg.cn/q=sh000001,...` | 用于补充振幅等字段 |

## 回测流程

```
输入：历史日K线（OCHL+volume）
   ↓
逐日模拟：对第 N 天，生成第 N+1 天预判
   ↓
对照第 N+1 天实际数据评分
   ↓
累计统计 → 月度分析 → 偏差分析
```

## 预判模拟逻辑（简化版）

基于当日收盘数据判断明日方向，不使用未来信息：

```
今日涨>1.5% + 振幅>3% → 震荡偏空（冲高回落风险）
今日涨>1.5% + 振幅≤3% → 偏多延续
今日涨0.5~1.5%         → 偏多/震荡
今日±0.5%以内           → 窄幅震荡
今日跌0.5~1.5%         → 偏空/震荡
今日跌>1.5% + 振幅>3% → 惯性下跌
今日跌>1.5% + 振幅≤3% → 偏空/弱反弹
```

区间计算：
- 支撑 = 今日最低价 × (1 - 0.8% × 波动因子)
- 压力 = 今日最高价 × (1 + 0.8% × 波动因子)
- 波动因子：振幅>4%→1.5, 振幅<1%→0.6, 默认1.0

## 评分体系

| 维度 | 满分 | 判定 |
|------|:----:|------|
| 方向分 | 1.0 | 预判方向与实际涨跌方向一致=1.0，否则=0.0 |
| 区间分 | 1.0 | 收盘在支撑/压力之间=1.0，否则按偏离度线性衰减 |
| 综合分 | 0-100 | (方向分+区间分)/2 × 100 |

方向判定规则：
- 偏多类预判 → 实际涨>0 则方向正确
- 偏空类预判 → 实际跌<0 则方向正确
- 窄幅震荡 → 实际|涨跌|<1% 则方向正确

## 统计输出

### 月度统计
```
2026-03: 21天  方向15/21(71%)  区间20/21(95%)  综合84/100
2026-04: 21天  方向13/21(62%)  区间20/21(95%)  综合80/100
```

### 偏差分析
- **实际上涨日预测正确率** vs **实际下跌日预测正确率**
- **偏多预判正确率** vs **偏空预判正确率** — 发现系统性偏见
- **连续错误** — 最长连续错误天数，定位"震荡市"等难预测时段

## 关键发现（基于2026-03~07回测）

| 月份 | 方向准确率 | 市场特征 | 解读 |
|:----:|:---------:|---------|------|
| 3月 | 71% | 有趋势 | 框架有效 |
| 4月 | 62% | 中等波动 | 还行 |
| 5月 | 44% | 震荡横盘 | 低于随机，不回测局限 |
| 6月 | 62% | 恢复波动 | 回归正常 |
| 7月 | 62% | - | - |

### 核心结论
1. **60.7% 是只用 K 线的 baseline** — 完整三框架（MCP板块+持仓+产业逻辑）应更高
2. **震荡市 44% 不是框架的锅** — 回测只用 K 线，缺少真实系统的多维数据
3. **偏空预判系统性偏悲观**（正确率48%）— 回测逻辑的缺陷，非真实系统问题
4. **区间准确率 98% 太松** — 算法需要收紧，不应作为有效性指标
